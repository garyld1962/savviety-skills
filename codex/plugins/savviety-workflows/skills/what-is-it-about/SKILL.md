# What Is It About

Use this for content thesis extraction and outline discipline.

## Workflow

1. Gather the source material or user's rough idea.
2. Identify the central promise and audience.
3. Draft a single-sentence thesis.
4. Build an outline where each section directly supports the thesis.
5. Cut or quarantine tangents.

## Output

Return:

- thesis
- audience
- outline
- segments to cut or move
- unresolved questions
