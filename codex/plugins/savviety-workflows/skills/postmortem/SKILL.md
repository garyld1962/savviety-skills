# Postmortem

Read run artifacts, logs, commits, reviews, and user notes. Use `references/report-shape.md` for the report shape. `references/legacy/` is archival only.

Focus on evidence-backed process improvements, not blame. Separate isolated mistakes from changes worth making to skills, rules, hooks, or templates.
