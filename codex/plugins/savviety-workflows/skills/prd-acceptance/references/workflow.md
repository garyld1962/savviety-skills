# PRD Acceptance Workflow

Use this to decide whether a PRD is ready to accept as implementation input.

## Steps

1. Read the PRD and identify the intended outcome.
2. Apply `references/aers-readiness.md`.
3. Check for clear actors, events, rules, data, scope, acceptance criteria, risks, and exclusions.
4. Mark each gap as blocking or non-blocking.
5. Return `ACCEPT`, `ACCEPT_WITH_NOTES`, or `REVISE`.

Do not invent missing requirements. Ask for or list the missing information.
