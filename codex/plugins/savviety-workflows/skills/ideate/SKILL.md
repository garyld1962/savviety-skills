# Ideate

Use this when the input is still exploratory.

## Modes

- `idea`: clarify a broad product or workflow idea.
- `ba`: clarify users, outcomes, constraints, language, and acceptance signals.
- `tech`: compare feasible implementation approaches, tradeoffs, and risks.

## Workflow

1. Read the supplied prompt, document, or folder.
2. Identify the central problem, actors, constraints, and unknowns.
3. Ask focused questions only when missing information blocks useful direction.
4. Produce 2-4 viable directions with tradeoffs.
5. Recommend the next decision or artifact.

Do not jump into implementation planning until the direction is selected.
