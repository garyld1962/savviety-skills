# Professional Review Workflow

Use this for seniority and craft grading after functional code review.

## Steps

1. Review the diff intent and implementation shape.
2. Apply `references/professional-rubric.md`.
3. Grade craft, maintainability, abstraction fit, test quality, operability, and delivery discipline.
4. Separate blocking quality issues from coaching notes.
5. Provide a concise final grade and the few changes that would most improve the work.

Do not duplicate normal `code-review` findings unless they affect the professional grade.
