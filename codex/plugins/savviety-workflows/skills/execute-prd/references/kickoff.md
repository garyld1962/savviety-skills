# Lightweight Kickoff

Use this when the input is smaller than a full PRD but still needs structure before implementation.

## Steps

1. Restate the requested outcome.
2. Identify impacted surfaces and likely files.
3. List assumptions and blockers.
4. Produce a short implementation plan with verification.
5. Ask for confirmation only when scope or correctness would be materially affected.

Escalate to the full `execute-prd` workflow when the work touches security, data migrations, public contracts, multi-package changes, or unclear acceptance criteria.
