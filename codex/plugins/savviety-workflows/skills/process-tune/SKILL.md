# Process Tune

Use this after multiple runs expose repeated workflow problems.

## Workflow

1. Gather postmortems, review notes, incident notes, and run artifacts.
2. Group repeated failures by taxonomy: planning, verification, review, delegation, config, delivery, docs, or tooling.
3. Separate one-off mistakes from process defects.
4. Propose targeted edits to skills, references, templates, rules, or hooks.
5. Do not change process assets until the user accepts the proposed edits, unless they asked you to implement directly.

## Output

For each recommendation include:

- evidence
- proposed asset to change
- exact behavior change
- confidence
- risk of overfitting
