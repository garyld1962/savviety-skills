# Thesis

Use this when scope feels scattered or the core claim is unclear.

## Workflow

1. Ask for or infer the audience, desired outcome, and non-goals.
2. Produce candidate one-sentence theses.
3. Pressure-test each thesis for specificity, falsifiability, and usefulness.
4. Select or refine one thesis.
5. Classify planned features or sections as direct, supporting, indirect but necessary, or off-thesis.

## Output

Return the final thesis, supporting rationale, scope audit, and recommended cuts or clarifications.
