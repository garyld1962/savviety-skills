# Postmortem Report Shape

Use after an `execute-plan` run warns, fails, exhausts retries, escalates, or reveals a workflow defect.

## Inputs

- Execution report.
- Verification logs.
- Review findings and dispositions.
- Commits and plan deviations.
- User notes or interruptions.

## Sections

- `Run reference`
- `What happened`
- `What worked`
- `What broke down`
- `What the process missed`
- `Recommendations`

## Recommendation Types

- Plan quality.
- Tooling or environment.
- Test coverage.
- Review coverage.
- Workflow instruction.
- Repo architecture.

Keep recommendations actionable and tied to observed evidence.
