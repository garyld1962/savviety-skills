# Sync Main Workflow

Use this to update the current branch from the repo default branch.

## Steps

1. Identify the default branch from repo config or project instructions.
2. Show current branch and working tree status.
3. Refuse to discard local changes.
4. Fetch the remote default branch when network access and approval allow it.
5. Merge or rebase only according to the user's request or repo convention.
6. Run focused verification after conflict resolution.
7. Report commits incorporated, conflicts resolved, and verification.

Do not force push or reset without explicit user instruction.
