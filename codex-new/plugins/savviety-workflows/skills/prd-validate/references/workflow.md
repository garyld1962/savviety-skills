# PRD Validate Workflow

Use this as an AERS readiness gate before plan generation.

## Steps

1. Identify actors, events, rules, and state transitions.
2. Check acceptance criteria for testability.
3. Verify data contracts, integrations, and edge cases are explicit enough to plan.
4. Flag contradictions, ambiguous verbs, missing non-goals, and hidden dependencies.
5. Return `PASS`, `WARN`, or `FAIL` with concrete fixes.

Use `references/aers-readiness.md` for the detailed standard.
