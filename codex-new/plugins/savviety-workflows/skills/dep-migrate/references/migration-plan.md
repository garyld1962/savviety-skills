# Dependency Migration Plan

Use this to plan dependency upgrades or ecosystem migrations.

## Plan Sections

- Current dependency and version.
- Target dependency and version.
- Breaking changes.
- Affected packages and files.
- Migration steps.
- Test and build commands.
- Rollback path.
- Risks and unknowns.

Prefer official migration guides when available. If network access is unavailable, state that version and migration details may need verification.
