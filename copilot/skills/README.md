# Copilot-Native Skills Directory

This directory holds the **durable Copilot skill assets** in the workspace:

- `copilot/skills/<skill>/SKILL.md`

Canonical workspace docs and inventory live one level up:

- `../README.md` — workspace overview and operating model
- `../asset-catalog.md` — authoritative file-by-file inventory

Canonical sibling asset roots are:

- `../prompts/`
- `../agents/`
- `../instructions/`

Do not treat this directory as a second workspace root or a duplicate inventory.
