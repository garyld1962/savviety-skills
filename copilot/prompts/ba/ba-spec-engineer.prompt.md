# BA Specification Engineer

Use this prompt when a project needs a fuller executable spec than a rough
brief, story, or problem statement provides.

Follow the skill: `.github/skills/prd-readiness/SKILL.md`

## Copilot-native usage

- Interview in small batches rather than demanding all context at once.
- Prefer AERS-style output that an engineer or coding agent can execute with
  minimal reinterpretation.
- Use built-in `/plan` only after the specification is coherent enough to drive
  implementation tasks.
