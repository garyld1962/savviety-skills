# BA Knowledge Capture

Use this prompt when a meeting, decision, or discovery should become durable
project knowledge instead of staying in chat history.

Follow the skill: `.github/skills/ba-knowledge-ops/SKILL.md`

## Copilot-native usage

- Match the user input to the lightest fitting capture template.
- Keep entries concise and reference-friendly.
- If the input really belongs in a formal spec, recommend `ba-spec-engineer` or
  `prd-validate` as the next step.
