# Postmortem workflow

Read the run artifacts, attempt history, actual changes and prior postmortems. Apply
[postmortem and decision reporting](../../skills/validate-plan/references/reporting.md).
Separate symptoms from evidenced causes; name recovery and a concrete reusable prevention
target. Save both postmortem.md and postmortem.json and append the existing index safely.
Do not edit shared workflow assets unless that change is part of the authorized request.
