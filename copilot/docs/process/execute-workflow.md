# Governed execution

Use [execute-prd](../../skills/execute-prd/SKILL.md) for requirements or
[execute-plan](../../skills/execute-plan/SKILL.md) for a written plan. The governed
entrypoint additionally requires professional and adversarial review, plus review-plan,
review-code, adversarial-review and disposition-log artifacts. Declare those gates at
preflight. Apply [the native execution contract](../../skills/validate-plan/references/execution.md)
with dependency-graph scheduling and truthful final-head evidence. Tools or independent
reviewers that a required gate needs must be available; otherwise report a blocker.
