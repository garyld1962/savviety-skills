# Document schema

Plans follow [the task graph contract](../../skills/validate-plan/references/plan-format.md).
Execution reports use native schema version 2 described in
[reporting](../../skills/validate-plan/references/reporting.md) and verified by
[validate_report.py](../../skills/validate-plan/scripts/validate_report.py).
Use the sibling templates for Markdown presentation; they are not alternative schemas.
